# 🎈 아이 놀이터 — 만 4세 인지 미니게임

만 4세 딸을 위한 **인지 발달 놀이 웹앱**입니다. 글자를 못 읽어도 **음성 안내·큰 버튼·아이콘**만으로 놀 수 있고,
**광고·결제·외부 링크가 전혀 없어** 부모가 안심하고 맡길 수 있습니다.

## 게임 구성

| 게임 | 기르는 능력 | 방법 |
|---|---|---|
| 🔢 개수 세기 | 수 개념 | 사물이 몇 개인지 세고 맞는 숫자 누르기 |
| 🔺 모양·색 분류 | 분류력 | 같은 색/모양을 모두 찾아 담기 |
| 🃏 짝 맞추기 | 기억력 | 카드를 뒤집어 같은 동물 짝 찾기 |
| 🌑 그림자 맞추기 | 관찰력 | 위 그림과 같은 검은 그림자 고르기 |

- 정답엔 ⭐별·칭찬 음성·색종이로 보상, 오답에도 부드럽게 다시 안내 → **실패 화면 없음**.
- 라운드를 거듭할수록 난이도가 조금씩 올라갑니다(개수·짝 수 증가).
- 우측 상단 🔊 버튼으로 소리를 끌 수 있습니다.

## 사용 방법 (가장 쉬운 순서)

### 1) 그냥 바로 써보기 (PC/노트북)
프로젝트 폴더에서 아래 한 줄 실행 후 브라우저에서 `http://localhost:8000` 접속:
```bash
python3 -m http.server 8000
```
> `index.html`을 더블클릭해 열어도 대부분 동작하지만, 일부 브라우저에선 위 방식이 더 안정적입니다.

### 2) 태블릿/폰에서 쓰기 (추천) — GitHub Pages 무료 호스팅
1. 이 저장소 GitHub 페이지 → **Settings → Pages**
2. **Source**를 `Deploy from a branch`로, 브랜치를 이 브랜치로 지정 후 저장
3. 잠시 뒤 생성되는 주소를 태블릿 브라우저에서 열기
4. 브라우저 메뉴의 **"홈 화면에 추가"**를 누르면 앱처럼 전체화면으로 실행됩니다(PWA).

## 기술 메모
- 순수 **HTML/CSS/JavaScript** (빌드 도구·외부 라이브러리 없음)
- 그래픽은 이모지·인라인 SVG로 처리 → **이미지 파일 불필요, 오프라인 동작**
- 음성은 브라우저 내장 `SpeechSynthesis`(한국어), 효과음은 `WebAudio`로 생성

## 폴더 구조
```
index.html          진입점(홈 + 게임 화면 틀)
manifest.json       홈 화면 설치(PWA) 설정
css/styles.css      전체 스타일
js/util.js          공용 도구(음성·효과음·보상·랜덤)
js/main.js          홈 화면 & 게임 전환
js/games/           게임별 로직 (counting, sorting, memory, shadow)
```
