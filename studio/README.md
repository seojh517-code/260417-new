# 🎨 그림 놀이터 — 그리기·색칠·스티커 (독립 앱)

만 4세 딸을 위한 **그림 창작 앱**입니다. 기존 "아이 놀이터" 게임 앱과는 **완전히 별개**로,
이 `studio/` 폴더만으로 독립 실행됩니다. **아이패드 + 애플펜슬**을 지원합니다.

## 두 가지 모드

### 🎨 그리기
- 빈 도화지에 자유롭게 그리기
- **8가지 화구**: 연필 · 펜 · 만년필 · 색연필 · 크레파스 · 파스텔 · 수채화 · 유화 (질감이 다 다름)
- 굵기 슬라이더, 12색 팔레트 + 직접 색 고르기(🎨)
- 지우개 🧽, 물통 🪣(내가 그린 선 안을 한 번에 채우기)
- **스티커** 🌟: 동물·자연·얼굴·탈것·하트 등 + **내 스티커 추가**(사진 업로드)
- 되돌리기 ↩️ / 다시실행 ↪️, 전체 지우기 🗑️, 저장 💾(PNG)

### 🖍️ 색칠하기
- 기본 도안: **캠핑 · 놀이터 · 그림 그리기**(선화) + 사과·꽃·집·물고기·나비·자동차
- **내 도안 추가**: 사진(선화 PNG/JPG)을 올려서 그 위에 색칠
- **자동칠 🪄 토글**: 켜면 영역을 탭해서 자동으로 색칠(선 밖으로 안 나감), 끄면 붓으로 직접 칠하기
- 그리기 모드와 같은 화구·지우개·되돌리기·저장 모두 사용

## 애플펜슬 / 아이패드
- Pointer Events로 **필압**(누르는 세기 → 굵기/진하기), 정밀 입력 지원
- 펜으로 그릴 때 **손바닥이 닿아도 그려지지 않음**(오터치 방지)
- 레티나 고해상도로 선이 또렷

## 실행 방법

### 컴퓨터에서 바로
프로젝트 루트에서:
```bash
python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000/studio/` 접속.

### 아이패드에서 (추천)
1. GitHub **Settings → Pages**로 이 브랜치를 배포
2. 생성된 주소 끝에 `/studio/` 를 붙여 아이패드 사파리에서 열기
   (예: `https...github.io/260417-new/studio/`)
3. 공유 버튼 → **홈 화면에 추가** → 앱처럼 전체화면 실행

## 기술 메모
- 순수 **HTML/CSS/JavaScript** (빌드 도구·외부 라이브러리 없음)
- 칠은 선(윤곽선) 아래 레이어에 깔리고(`mix-blend-mode: multiply`) 선은 항상 위에 또렷하게 유지
- 자동칠은 픽셀 단위 **플러드 필**(어두운 선을 경계로 멈춤)
- 되돌리기/다시실행은 캔버스 스냅샷 스택
- 업로드한 도안·스티커는 **브라우저 안에서만** 처리(서버 전송 없음), `localStorage`에 저장되어 다음에도 보임

## 참고
- 수채화·유화 등은 느낌을 흉내 낸 **근사 표현**입니다(실물 물감 재현은 아님).
- 실제 애플펜슬 필압은 **아이패드 실기기**에서 가장 잘 확인됩니다.
- 폴더 구조
  ```
  studio/index.html        진입점(홈 + 스튜디오)
  studio/css/styles.css    스타일
  studio/js/util.js        공용 유틸(독립)
  studio/js/main.js        홈 ↔ 모드 전환
  studio/js/art/engine.js  페인트 엔진(펜슬·물통·Undo)
  studio/js/art/ui.js      도구 바 + 도안/스티커 시트
  studio/js/art/brushes.js 화구 8종
  studio/js/art/stickers.js 기본 스티커
  studio/js/art/templates.js 기본 도안
  studio/assets/templates/ 번들 선화 이미지
  ```
